> 仓库当前是 `17.1.2 / schema 19 / candidate-local-only`，本地门禁不会自动触发发布，需按 A→Tag→部署→B 的授权流程执行。线上仍是 2026-07-22 完成核验的 V17.0.0。V18 静态加密门禁为 **NO-GO**，不要把候选功能或写门禁说成已发布加密。

## 一句话定位

时屿不是“能放图片的备忘录”，而是一座本地优先的私人记忆博物馆：文字先保存，照片和声音随后关联，AI 或规则只给可编辑草稿；找回、关系、分享与事实判断都保留给用户。

## 这条路线想证明什么

1. **产品问题**：备忘录能记下，却不容易多年后按画面找回，也很少解释 AI 和数据边界。
2. **核心闭环**：原文先存 → 媒体关联 → 可选整理 → 人工确认 → 多种方式找回。
3. **差异点**：阿棠双记录和时光拼图展示“系统整理证据，但不裁决记忆真相”。
4. **工程可信**：公开 Demo 零写入、运行时信任合同、服务端签名执行回执、并发更新与隔离恢复都有机器门禁。
5. **诚实限制**：PWA 不是原生 App，设备语义不是事实判断，写门禁不是静态加密，本地恢复不是异机灾备。

## 公开 Demo 与本地版

| 能力 | 公开网址 | 私人本地环境 |
|---|---|---|
| 四件虚构展品、搜索、详情、固定问题 | 只读可用 | 可用 |
| 新增、修改、删除 | 所有非 `GET/HEAD` 在正文前拒绝 | 可用 |
| 图片、声音、备份 | 不接收 | 保存在本机目录 |
| 记忆整理/讲解 | 公开 Mock 或本地规则 | 默认本地规则；配置外部模型后逐次同意 |
| 设备语义 | 用户主动加载，同源 WASM | 同样按需加载 |
| SQLite/媒体静态加密 | 未实现 | 未实现 |
| 账号、私人云同步 | 无 | 无 |

## AI 标签怎么解释

- **本地规则**：固定算法或证据检索，没有调用外部模型。
- **公开 Mock**：只针对固定虚构样例生成演示结果，不是假装真实推理。
- **设备 embedding**：同源模型在浏览器 Worker/WASM 中计算，只做文本相似排序。
- **外部模型**：只有非 Demo 环境、已配置 Key、合同匹配且用户对本次输入明确同意时才会调用。
- **确定性策展工作流**：固定预算和四项只读工具的状态机，不是自治 Agent，也没有后台循环、任意工具或自动发布权限。

## 30 秒技术回答

“前端是原生 HTML/CSS/JavaScript 的响应式 PWA，后端是 Node.js 24 原生 HTTP 服务，数据用 SQLite 和 FTS5，图片与声音走内容寻址文件存储。设备语义用 Transformers.js、ONNX WASM 和 `bge-small-zh-v1.5` q8。并发修改用 ETag/If-Match，备份用自校验 `.time-isle`，公开 Demo 则在正文读取前统一禁写。外部 AI 同意绑定提供方、模型、发送字段、用途和本次输入，服务端再签发执行回执。”

## 常见追问

### 这是原生 App 吗？

不是。它是手机和桌面共用的响应式 Web/PWA；可以安装到主屏幕，但私人馆藏仍依赖对应的本地 Node 服务，不提供账号或跨设备同步。

### 为什么不把所有搜索做成 AI？

因为三种意图成本不同：记得词就用字段检索；只记得画面才加载设备 embedding；要跨多件记忆总结才用讲解员。这样默认路径快、清楚，也不会为一个名字下载 47 MB 模型。

### AI 会上传我的原文吗？

默认不会。整理和讲解默认走本地规则；设备语义在本页 Worker 内运行。外部模型只有用户看过提供方、模型、发送字段并对本次操作同意后才可调用，公开 Demo 永远禁用。

### 语义第一名就是正确答案吗？

不是。它只是文本相似度排序，没有馆外拒答阈值，也不能判断事实、人物关系、情绪、真实性或概率。

### 这是会自己行动的 Agent 吗？

不是。历史代码模块名保留 `curator-agent`，但产品准确称为“确定性策展工作流”。它只读查证并输出未保存提案；保存草稿、确认关系、发布和分享是彼此独立的人工作决定。

### 锁馆或共忆加密等于数据库加密吗？

不等于。共忆文件和离线分享使用浏览器端 AES-GCM，但确认入馆后的内容、SQLite、图片和声音仍是本机明文。应用锁馆只阻止新的应用写请求。V18 因跨平台加密证据不足保持 NO-GO。

### 恢复演练通过代表灾备完成吗？

不代表。V15 会真的恢复到一次性 SQLite/媒体副本并销毁，但只证明当前机器、当前版本能恢复，不证明另一设备、RTO/RPO 或生产灾备。

### SHA-256 能证明记忆真实吗？

不能。它用于内容身份、来源变化和修订父链完整性，不是数字签名、可信时间戳或事实证明。

## 演示失败时怎么收口

- CloudBase 冷启动：等待唤醒页的有限重试，不连续刷新或开启常驻实例；失败后切 Vercel 或本地后备。
- 设备语义不支持：明确说“当前浏览器/WASM 不可用”，回到字段检索，不把后备结果冒充语义命中。
- 网络不稳定：只演示本地虚构数据；不要临时上传真实照片、录音或备份。
- 时间不足：停在“阿棠双记录 + 拼图 + 信任条”，这三处已足以讲清产品问题、人工决定和安全边界。
