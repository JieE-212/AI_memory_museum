# 时屿（TIME ISLE）

把零散文字、照片和声音整理成一座能找回、能回看、也能说明来源边界的私人记忆博物馆。

> 仓库当前是 **17.1.2 / schema 19 / candidate-local-only**。本地门禁通过不会自动扩大成发布事实；发布需按运行时提交 A → Annotated Tag → 双平台部署与探针 → 证据提交 B 的授权流程执行。最后完成生产核验的线上版本仍是 **17.0.0**。V18 真正数据库/媒体静态加密继续保持 **NO-GO**。

## 它解决什么问题

普通备忘录擅长“记下来”，却很难回答三个问题：几年后怎样找回来、照片和声音怎样与原文一起保存、AI 到底做了什么以及数据去了哪里。时屿把一段记忆当成“展品”：原文永远先保存，媒体随后关联，整理只是可选草稿，最终由用户确认。

## 三个核心亮点

1. **原文优先的多模态记忆**：文字先安全落库，图片或声音失败也不会带走原文；整理后更新同一件展品，不制造重复项。
2. **三层找回方式**：名字、地点或原句走字段与 FTS 检索；只记得一个画面时，可主动加载设备内中文 embedding；跨多件记忆的问题交给带引用的讲解员。
3. **可见的信任边界**：四个主视图上方持续显示保存位置、AI 引擎、是否外发和静态加密状态。外部 AI 必须逐次展示提供方、模型和发送字段，并使用内容绑定合同与服务端签名回执。

### 本地可写体验

需要 Node.js 24 或更高版本：

```powershell
cd "<project-root>"
npm.cmd start
```

然后打开 <http://127.0.0.1:3000/#collection>。本地版把 SQLite、图片和声音保存在当前设备；关闭本地服务后，PWA 图标也不能独立访问私人馆藏。

## 四个普通用户入口

- **馆藏**：搜索、最近展品和照片优先；品牌说明与统计折叠为次级信息。
- **记录**：先点“保存记忆”，再关联媒体；整理、人物、标签、情绪和重要度均为后续可选信息。
- **找回**：字段检索、设备语义和讲解员先解释区别；今日回访随后展示，时间线、年轮、策展和镜片收进“更多回看方式”。
- **我的**：先显示数据位置、备份与安装；完整安全合同、恢复演练和技术栈放在“项目幕后”。

内部 hash 继续使用 `#collection / #compose / #reflect / #data`，以保持深链和 PWA 兼容。

## AI 与规则引擎的真实标签

| 能力 | 默认执行方式 | 外发 | 持久化 |
|---|---|---|---|
| 记忆整理 | 本地规则 | 默认不外发；配置外部模型后逐次同意 | 预览不保存，确认后更新同一展品 |
| 讲解员 | 本地证据检索 + 本地规则 | 默认不外发；配置外部模型后逐次同意 | 不保存回答 |
| 按意思找回 | 设备 embedding，Chromium WASM Worker | 不外发 | 向量与索引仅在本页内存 |
| 策展 | 确定性策展工作流 | 不外发 | 私人本地版仅在人工决定后保存 |
| 公开 Demo | 固定虚构样例 / 本地规则 | 禁止 | 零访客写入 |

`GET /api/runtime/trust` 是 UI 与测试共用的运行时合同。它只公开安全 origin，不返回 Key、认证头、URL 路径或查询参数。

## 技术结构

- 原生 HTML / CSS / JavaScript 响应式 Web 与 PWA 外壳
- Node.js 24 原生 HTTP 服务
- `node:sqlite`、SQLite FTS5 trigram 与参数化 LIKE 回退
- 内容寻址 WebP 图片、WebM/Ogg/MP4/WAV 声音与 Range 播放
- Transformers.js 3.8.1、`bge-small-zh-v1.5` q8、ONNX WASM 单线程
- If-Match 乐观并发、修订父链、可验证 `.time-isle` 归档与隔离恢复
- CloudBase / Vercel 公开只读 Demo，私人数据不进入公开部署

## 诚实边界

- 这是响应式 Web/PWA，不是原生 App；当前没有账号、私人云同步、多租户或公开社交。
- 私人本地 SQLite 与媒体目录仍是明文静态存储。应用锁馆是写门禁，不是磁盘加密。
- 语义相似度不是事实、情绪、人物关系、真实性或概率判断；当前也没有馆外查询拒答阈值。
- 共忆文件的浏览器端加密不等于身份认证或数字签名。
- CloudBase 会缩容到 0，有限冷启动可能短暂返回 503；项目不会为演示开启付费或常驻实例。
- Windows 无终端私人安装包、账号、云同步和真正静态加密都留给后续独立版本。
